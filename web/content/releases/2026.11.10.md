## Release Highlights (`2026.11.10`)

- **Native Liquid Glass MacShell Spotlight (`enerco-macshell 1.0.0-6`):**
  - Migrated search requests from legacy Rofi menus to the native `MacSpot` Cupertino Liquid Glass search modal.
  - Features real-time arithmetic calculations, application fuzzy matching with usage frequency ranking, and file indexing.
  - Packaged and pre-configured `cliphist` to provide instant clipboard history search with rich image thumbnail previews on `Super + V`.
  - Added native emoji picker modal accessible via `Super + .`.
  - Replaced legacy `"rofi"` launcher dock pin with `"chromium"` for a clean default 5-app dock layout.

- **Universal macOS Traffic Lights & Window Chrome (`WindowDecor`):**
  - Enabled native macOS window decorations and interactive traffic lights across **every application**—including Terminal (`kitty`), Chromium, Thunar, and system tools—matching the appearance of MacShell's System Settings.
  - **Red Light (`#FF5F57`):** Closes window (with subtle hover glyph `×` and Apple `"tink"` click audio feedback).
  - **Amber Light (`#FEBC2E`):** Minimizes window to special workspace (with hover glyph `−`).
  - **Green Light (`#28C840`):** Maximizes or toggles fullscreen (with hover glyph `↗`, Alt-click maximize, standard click fullscreen).
  - Dimmed monochrome state when windows lose focus; vibrant macOS colors restore upon hover or focus.
  - Centered window titles rendered in `Open Runde` typography.
  - Double-clicking the titlebar maximizes or restores the window; dragging smoothly detaches and moves tiled windows.
  - Configured `kitty.conf` with `hide_window_decorations yes` to eliminate competing CSD borders and guarantee clean titlebar integration.

- **Keybinding Unification & Layer Rules (`enerco-desktop-config 1.0.0-24`):**
  - `Super + Space`: Native MacShell Spotlight Search (`qs -c MacShell ipc call spotlight toggle`).
  - `Super + V`: Native Spotlight Clipboard History (`qs -c MacShell ipc call spotlight clipboard`).
  - `Super + .`: Native Spotlight Emoji Picker (`qs -c MacShell ipc call spotlight emoji`).
  - `Super + Shift + V`: Toggle window floating mode (`hl.dsp.window.float`).
  - `Alt + Tab` / `Super + Tab`: Native MacShell window switcher (`qs -c MacShell ipc call switcher next`).
  - Added `macspot` (`blur = true`, `ignore_alpha = 0.05`) and `macwindecor` (`no_anim = true`) layer rules to Hyprland.
